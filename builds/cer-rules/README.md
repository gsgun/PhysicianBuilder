# CER Rules Library

Reusable Clinical Event Engine patterns: criteria tables, property trees, trigger design.

Conventions:
- One doc per reusable pattern (not per build id); reference build ids from project folders.
- Every criteria row documented: trigger (event vs time), evaluation window, synthetic test values.
- Cross-build index of deployed CERs: `predicting-cvd-risk-events/`, `gupta-surgery-risk-scores/`, `admission-med-rec-tip-text/`, `cath-pci-gdmt/`.
